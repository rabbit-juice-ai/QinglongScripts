Credit Cookie 工具

从本机 Chrome 读取 credit.linux.do 登录态，生成青龙环境变量 CREDIT_COOKIE_JSON。页面只监听 127.0.0.1。
请通过本地工具打开本页面。 直接双击 index.html 只能看到界面，无法读取 HttpOnly cookie， 也无法启动 Chrome。请确保已下载整个 tools/credit-cookie 目录， 然后在其中运行：
cd tools/credit-cookie
python3 cookie_tool.py
工具会自动打开 http://127.0.0.1:8765/，请在那个地址操作。

      下面的 JSON 就是可粘贴到青龙的 CREDIT_COOKIE_JSON， 包含当前 Chrome 里所有相关 cookie。缺失项需要先在 Chrome 登录对应站点， 工具无法凭空生成。

      使用步骤

      1. 在 tools/credit-cookie 目录运行 python3 cookie_tool.py， 不要直接双击 index.html。工具会自动打开 http://127.0.0.1:8765/。
      2. 点 启动 Chrome。工具会用独立 profile 启动一个带调试端口的 Chrome。
      3. 在打开的 Chrome 里登录 credit.linux.do/balance，完成 Cloudflare 或人机验证，直到能看到余额。
      4. 如果只读到 linux_do_credit_session_id，先点 打开 linux.do 登录，再点 打开 connect，然后重新读取。这样 JSON 才会包含 _forum_session、_t 和 auth.session-token。
      5. 回到本页点 读取 Cookie，再点 复制 JSON。
      6. 在青龙「环境变量」新增 CREDIT_COOKIE_JSON，粘贴 JSON。
      7. 青龙定时任务只需要 credit_browser.py；脚本在 profile 没有有效会话时自动导入。
      安全提示：生成的 JSON 等同于登录凭据，不要截图、不要发到群里。 cf_clearance 和出口 IP、User-Agent 绑定，导入青龙后通常会失效， 默认不导出。用完可以点「清空」从页面移除。
